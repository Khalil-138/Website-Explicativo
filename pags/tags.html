HTML - Linguagem de Marcação de Hipertexto

HTML é a base de toda a web. É uma linguagem de marcação usada para criar e estruturar conteúdo na web.

O que é HTML?

HTML (HyperText Markup Language) é a linguagem fundamental para a criação de páginas web. Diferente de linguagens de programação, o HTML é uma linguagem de marcação que utiliza "tags" para estruturar e apresentar conteúdo na internet.

Criado por Tim Berners-Lee em 1991, o HTML evoluiu significativamente ao longo dos anos, com a versão mais recente sendo o HTML5, que introduziu novos elementos semânticos e recursos multimídia nativos.

Linguagem de Marcação

Não é uma linguagem de programação, mas sim de marcação que define a estrutura do conteúdo

Baseado em Tags

Utiliza elementos (tags) para definir diferentes partes do conteúdo

Interpretado por Navegadores

Os navegadores web interpretam o HTML para exibir páginas

Por que aprender HTML?

HTML é a espinha dorsal da web moderna. Sem ele, não existiriam sites, aplicações web ou conteúdo online estruturado.

Universalidade

Funciona em todos os navegadores e dispositivos

Fácil Aprendizado

Sintaxe simples e intuitiva para iniciantes

Base para Outras Tecnologias

CSS e JavaScript dependem do HTML

SEO Amigável

Estrutura semântica que os mecanismos de busca entendem

Estrutura Básica de um Documento HTML

Todos os documentos HTML seguem uma estrutura básica que inclui declarações, elementos de cabeçalho e corpo.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Título da Página</title>
</head>
<body>
    <h1>Meu Primeiro Cabeçalho</h1>
    <p>Meu primeiro parágrafo.</p>
</body>
</html>

Tags de Estrutura Básica

<html>

Elemento raiz que envolve todo o conteúdo HTML da página.

Atributos Principais:

  • lang - Define o idioma do documento
<html lang="pt-BR">
  <!-- Conteúdo da página -->
</html>

<head>

Contém metadados sobre o documento, como título, codificação de caracteres e links para recursos externos.

<head>
  <meta charset="UTF-8">
  <title>Minha Página</title>
</head>

<body>

Contém todo o conteúdo visível da página web.

<body>
  <h1>Conteúdo Principal</h1>
  <p>Texto da página...</p>
</body>

Tags de Metadados

<title>

Define o título da página, mostrado na aba do navegador e nos resultados de busca.

<title>Meu Site - Página Inicial</title>

<meta>

Fornece metadados sobre o documento HTML.

Atributos Principais:

  • charset - Define a codificação de caracteres
  • name - Nome do metadado
  • content - Conteúdo do metadado
<meta charset="UTF-8">
<meta name="description" content="Site sobre HTML">
<meta name="keywords" content="HTML, tutorial, web">
<meta name="author" content="Seu Nome">

Listas

<ul>

Define uma lista não ordenada (com marcadores).

  • Item da lista 1
  • Item da lista 2
  • Item da lista 3
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

<ol>

Define uma lista ordenada (com números).

  1. Primeiro item
  2. Segundo item
  3. Terceiro item
<ol>
  <li>Primeiro item</li>
  <li>Segundo item</li>
  <li>Terceiro item</li>
</ol>

<li>

Define um item de lista, usado dentro de <ul> ou <ol>.

<li>Item da lista</li>

Links e Mídia

<a>

Define um hyperlink para outras páginas ou recursos.

Atributos Principais:

  • href - URL do destino do link
  • target - Como abrir o link (_blank para nova aba)
  • download - Força o download do recurso

Link interno | Link externo

<a href="https://exemplo.com">Visite nosso site</a>
<a href="#secao">Link interno</a>
<a href="arquivo.pdf" download>Download</a>

<img>

Insere uma imagem na página.

Atributos Principais:

  • src - Caminho para a imagem
  • alt - Texto alternativo (acessibilidade)
  • width/height - Dimensões da imagem
  • title - Título da imagem
<img src="imagem.jpg" 
     alt="Descrição da imagem"
     width="200" 
     height="100">
